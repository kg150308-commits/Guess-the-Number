### Guess The Number
<br>
Guess the Number is a fun, interactive number-guessing game where players try to find a randomly generated number between 1 and 100. The game provides hints after each guess to help players reach the correct answer. It also tracks the number of attempts and keeps a record of your best score. Built using HTML, CSS, and JavaScript.
